# Lucky World Invasion - Hardcore Mode Dependencies

## Required Core Base
- Minecraft Forge (Version matching LWI base)
- KubeJS (For script adjustments and custom logic)
- Packwiz (For modpack packaging and dependency management)

## Mod Retentions (QoL & Core)
- `sophisticatedbackpacks` (or equivalent QoL inventory mod)
- `lucky` (Base Lucky Block mod)
- Custom Lucky Block Addons (Moved to Overworld)
- Core optimization mods (Embeddium/Rubidium, EntityCulling, etc.)

- `touhou_little_maid`
