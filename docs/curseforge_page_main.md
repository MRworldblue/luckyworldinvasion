## Description

## Lucky World Invasion Modpack

_A thrilling fusion of lucky blocks and survival challenges where danger escalates with each opened block_

## Overview

This modpack combines the chaotic fun of lucky blocks with intense invasion mechanics. The Ender Dragon has been significantly buffed - you'll need powerful gear before daring to enter The End. But beware: sleepless nights of invasions may overwhelm you before you're ready.

## Key Features

### 🏝️ Unique Skyblock Experience

-   Pre-built racing maps via Skyblock Builder (no manual world downloads needed)
-   Custom terrain generation optimized for competitive play

### 💥 Dynamic Invasion System

-   Progressive difficulty scaling with delayed start (21-day grace period)
-   Special sky effects (shader-incompatible warning)
-   Team-based survival challenges

### 🔫 Enhanced Combat

-   Tacz firearm system for realistic FPS mechanics
-   Smart AI mobs that adapt to player tactics
-   Rebalanced gunplay and weapon progression

## FAQ

### 🗺️ How to select racing maps?

`Create World » World Type: Skyblock » Customize » Select Race Map`

### 🌌 Shader Compatibility

While shaders work, the invasion sky effects will be disabled. For full experience, we recommend playing without shaders.

### ⏳ Event Trigger System (v2.3+)

-   Random player selection after countdown
-   Inventory auto-consumption for event cancellation
-   Real-time HUD notifications
